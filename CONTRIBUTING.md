# Contributing

Corrections are welcome. Exam guides change, and a study guide is only useful if it's accurate.

- **Report an error:** open an issue with the topic, what is wrong, and a link to the official exam guide or vendor documentation that shows it.
- **Suggest an improvement:** open an issue first so we can agree on it before you write a pull request.

This guide is generated from the SaveMyCert content library, so fixes are made at the source and then republished here. That keeps this repo and the website in sync.
